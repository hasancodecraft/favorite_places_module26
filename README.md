# Favorite Places

A small Flutter app for the Module 26 Google Maps & Location assignment.

The app opens a Google Map with three predefined places in Dhaka. The My Location button requests location access, gets the device's coordinates with `geolocator`, and moves the map to that position. Tapping a favorite marker opens its details. The Favorite Locations button opens a list, and selecting a place moves the map there.


Screenshots were taken with a Maps Demo Key on Flutter web (no billing account). To run on Android, see docs/START_HERE_BN.md.
